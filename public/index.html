SATNEX Architecture & Data Sources

Architecture Highlights

  • KeepTrack API V4: Integrated via single bulk fetch (/v4/sats/brief) with ETag validation and 1-hour disk cache.
  • Orbital Mechanics: Powered client-side by KeepTrack's official OOTK (Orbital Object Toolkit v8.2.0) SGP4 engine without continuous API position polling.
  • 3D Earth Globe: Powered by CesiumJS using Esri World Imagery (satellite composite) and CartoDB boundaries & geographic labels.
  • Historical & Future Simulation: Computes true orbital dynamics across arbitrary timestamps with clear distinction between simulated orbits and modern base Earth imagery.
